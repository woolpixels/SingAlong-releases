# 一起唱 · SingAlong

macOS 桌面歌词工具。

自动识别 Apple Music 与 Spotify 正在播放的歌曲，
把同步歌词放在桌面上，跟着播放进度逐行滚动。

无需账号，无需配置。

---

## 主要功能

### 悬浮歌词

- 无边框悬浮歌词窗口
- 随播放进度逐行高亮
- 支持小 / 中 / 大三档尺寸
- 可自由拖动位置
- 支持透明背景
- 支持一键回到屏幕中央

### Apple Music / Spotify

自动识别：

- 当前歌曲
- 歌手
- 播放进度
- 播放状态

歌词通过 LRCLIB 自动匹配，无需 API Key。

### 状态栏歌词

可以选择在 macOS 菜单栏图标旁，
同步显示当前正在唱的那一句歌词。

不需要时可以关闭。

### 外观

支持：

- 深色
- 浅色
- 跟随系统

高亮歌词颜色可选：

- 默认
- 红
- 橙
- 黄
- 绿
- 蓝
- 紫
- 跟随系统强调色

### 启动行为

可以选择：

**默认状态启动**

每次打开时恢复到安全的默认状态：
- 关闭点击穿透
- 显示背景
- 回到默认位置

**继续上次的位置与状态**

恢复上次退出时的：
- 窗口位置
- 点击穿透
- 透明背景状态

这样即使上次把窗口藏到了角落，也不容易出现“启动了但找不到”的情况。

### 开机自动启动

可以在菜单栏中直接开启或关闭。

### 每日播放记录

自动记录当天完整播放完的歌曲，包括：

- 歌名
- 歌手
- 专辑
- 播放次数
- 当天累计听歌时长

并生成当天的「今日歌词精选」。

记录保存在本机，不上传。

### macOS

适用于：

- macOS 13+
- Apple Music
- Spotify

首次运行时，macOS 会请求「自动化」权限，
用于读取 Apple Music / Spotify 当前播放信息，请选择允许。

## 使用方式

1. 打开一起唱
2. 播放 Apple Music 或 Spotify
3. 一起唱会自动识别当前歌曲
4. 匹配到歌词后，悬浮窗会开始同步滚动

其他设置都可以从菜单栏图标中调整。

---

## 隐私

一起唱不需要账号。

- 不上传你的音乐文件
- 不保存你的音乐内容到云端
- 播放信息只用于歌词匹配与本地显示
- 播放记录保存在本机
- 当前歌词快照也只写入本机
